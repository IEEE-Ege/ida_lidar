# IDA LiDAR Perception (MAVİ İNCİ) 🌊🛥️

**A ROS 2 Jazzy perception stack for autonomous Unmanned Surface Vehicles (USVs).**

This package contains the `buoy_lidar` node, an edge-optimized C++ point cloud processing pipeline designed for the MAVİ İNCİ autonomous boat. It ingests 3D LiDAR data, utilizes the Point Cloud Library (PCL) for obstacle extraction, and integrates ROS 2 `tf2` spatial transformations to map maritime buoys in global coordinates.

## 🚀 Key Features
* **Native ROS 2 Integration:** Fully compatible with ROS 2 Jazzy Jalisco.
* **Gazebo Harmonic Ready:** Out-of-the-box support for simulated maritime environments and `ros_gz_bridge`.
* **Edge-Optimized PCL Pipeline:** Utilizes Voxel Grid downsampling and RANSAC plane removal to maintain high framerates on embedded hardware (e.g., Jetson Nano).
* **Global Spatial Tracking:** Uses `tf2` to transform local LiDAR hits into stable, global map coordinates (`odom` / `map`), preventing phantom object generation during boat movement or wave-induced pitch/roll.

## 📋 Prerequisites
This package is built for **ROS 2 Jazzy**. Ensure you have the following system dependencies installed:

```bash
sudo apt update
sudo apt install ros-jazzy-tf2-ros ros-jazzy-tf2-geometry-msgs ros-jazzy-geometry-msgs ros-jazzy-ros-gz libpcl-dev
```

📡 Node Details: buoy_lidar
Subscribed Topics
/gazebo_lidar/points (sensor_msgs/msg/PointCloud2): The raw 3D point cloud generated by the virtual sensor.

Published Info / Output
The node currently logs the mathematical centroid of detected buoy clusters to the terminal, mapped to global coordinates.

TF Frames
Requires: odom -> base_link -> lidar_link

The node extracts spatial data from lidar_link and mathematically resolves it to the global odom frame using an integrated tf2_ros::TransformListener.
